# Adivina el Número 🎮

Un minijuego clásico de consola desarrollado en Python. El objetivo es descubrir un número secreto generado al azar utilizando la lógica y pistas antes de quedarte sin intentos.

## Cómo jugar
1. La computadora elegirá un número aleatorio entre el 1 y el 50.
2. Tienes 5 intentos (vidas) para adivinarlo.
3. En cada turno, deberás ingresar un número. Si fallas, el juego te dará una pista indicando si el número secreto es **MAYOR** o **MENOR** al que ingresaste.
4. Ganas si aciertas el número exacto. Pierdes si tu contador de intentos llega al límite.
